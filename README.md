# Personal Portfolio — HTML/CSS/JS with Gulp Automation

Hello and welcome to my GitHub profile!  

This is my **personal portfolio**, originally built using **pure HTML, CSS, and JavaScript**, but enhanced with **Gulp automation**.  

While Gulp is often thought of as "just a task runner", in this project it served as a **powerful development accelerator**, allowing me to:  

- Compile and optimize assets automatically  
- Implement modular **HTML/CSS/JS components** that mimic the structure and reusability of React components  
- Rapidly iterate and deliver a **high-quality, large-scale project** in minimal time  

This project demonstrates how traditional web technologies can be combined with modern automation tools to create **scalable and maintainable front-end architectures** without relying on full frameworks.  

---

## Key Highlights

- Modular, component-like HTML/JS structure for better maintainability  
- Fully automated build process with Gulp: minification, live reload, asset optimization  
- Responsive and interactive design  
- Demonstrates ability to work **fast and efficiently** on large front-end projects
